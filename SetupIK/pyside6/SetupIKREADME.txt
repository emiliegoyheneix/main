In Maya : Drag and drop the SetupIK_launcher.py file into the viewport.
In 3DSMax : Drag and drop the SetupIK_launcher.ms file into the viewport.

If you use 2025, take the pyside6 folder.

This script setup your IK(Soft, Squesh, Stetch, Length).

Steps:
1. Select the handle in maya(or chain in 3dsmax).
2. Select a name (or check the default checkbox).
3. Click on "Setup" button.
